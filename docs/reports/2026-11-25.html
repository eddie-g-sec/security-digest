DockerCVE-2026-135124UNSCORED

Summary: A race condition during docker cp mount setup in Docker Engine allows a malicious container to leave a read-only bind mount writable while an archive is extracted into the container. When copying files into a container, the daemon bind-mounts the container's volumes into a temporary view and applies the read-only flags afterwards, through a path inside the container's filesystem. A process in the container can change that path in between, so the flags are applied to a different mount and the intended bind mount stays writable for the duration of the copy.
