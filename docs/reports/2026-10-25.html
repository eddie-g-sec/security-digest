Scoped Vulnerability Tracking

Cloud Security

The most urgent issue this cycle is CVE-2026-44181 (CVSS 10.0) in Jupyter Enterprise Gateway, a critical server-side template injection (SSTI) flaw that allows unauthenticated attackers to execute arbitrary Python code and OS commands on the gateway service, potentially stealing Kubernetes service-account tokens and fully compromising the cluster. This vulnerability affects both Kubernetes and Docker Swarm deployments running versions 2.0.0rc2 through 3.2.x, and a patch is available in version 3.3.0. No CISA KEV-confirmed exploits are present in today’s formal vulnerability feed, so the highest theoretical severity drives priority.

Formal Vulnerabilities

Microsoft AzureCVE-2026-50516CVSS 9.4 · CRITICAL

Summary: An incorrect authorization flaw in Azure Kubernetes Service (AKS) allows an authorized attacker to elevate privileges over the network. The vulnerability stems from insufficient authorization checks, enabling a user with existing access to gain higher permissions within the cluster.

Affected Features / Interoperability: Azure Kubernetes Service (AKS) control plane authorization. Downstream impacts could include unauthorized cluster administration, workload manipulation, and potential access to attached Azure resources via managed identities.

Source: https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-50516

Actions:

  • Fix: Apply the security update provided via the Microsoft Security Response Center (MSRC) advisory; no specific version number is published in the advisory.
  • Workaround: Restrict network access to the AKS API server using authorized IP ranges and enforce least-privilege RBAC roles.
  • Tradeoff: IP restrictions may hinder legitimate remote administration; RBAC tightening requires careful role auditing.
Microsoft AzureCVE-2026-68870CVSS 5.3 · MEDIUM

Summary: In Apache Airflow’s Microsoft Azure provider (multi-team mode with Azure Key Vault secrets backend), a team-scoped connection or variable ID can be resolved through a team-agnostic lookup when the team-scoped lookup misses, allowing a user in one team to read another team’s secrets by supplying an ID that spells out the target team’s namespace.

Affected Features / Interoperability: Apache Airflow’s `apache-airflow-providers-microsoft-azure` package, specifically the Azure Key Vault secrets backend when multi-team mode is enabled. Impacts secret isolation between teams.

Source: https://github.com/apache/airflow/pull/70876, https://github.com/apache/airflow/pull/70899, https://lists.apache.org/thread/dtkk6vtfoj1y4zjyd6s3mzg0v5g9yg0p, http://www.openwall.com/lists/oss-security/2026/08/10/4

Actions:

  • Fix: Upgrade to `apache-airflow-providers-microsoft-azure` 14.1.0 or later.
  • Workaround: Disable multi-team mode or avoid using the Azure Key Vault secrets backend until upgraded.
  • Tradeoff: Disabling multi-team mode removes team isolation features; alternative secrets backends may require migration effort.

KubernetesCVE-2026-44181CVSS 10.0 · CRITICAL

Summary: Jupyter Enterprise Gateway (versions 2.0.0rc2 through 3.2.x) is vulnerable to Server-Side Template Injection (SSTI) via environment variables (`KERNEL_XXX`) used during Kubernetes manifest rendering. Attackers can inject Jinja2 template expressions to execute arbitrary Python code and OS commands, steal Kubernetes service-account tokens, and fully compromise the cluster.

Affected Features / Interoperability: Jupyter Enterprise Gateway’s Kubernetes manifest rendering. Impacts any Kubernetes or Docker Swarm cluster where the gateway launches kernels; downstream compromise includes secret theft and cluster takeover.

Source: https://github.com/jupyter-server/enterprise_gateway/releases/tag/v3.3.0, https://github.com/jupyter-server/enterprise_gateway/security/advisories/GHSA-f49j-v924-fx9w

Actions:

  • Fix: Upgrade to Jupyter Enterprise Gateway 3.3.0.
  • Workaround: Restrict who can set `KERNEL_XXX` environment variables; run the gateway with minimal service-account permissions.
  • Tradeoff: Restricting environment variables may break legitimate kernel customization; least-privilege service accounts may limit required cluster operations.

Source: https://github.com/jupyter-server/enterprise_gateway/releases/tag/v3.3.0, https://github.com/jupyter-server/enterprise_gateway/security/advisories/GHSA-cfw7-6c5v-2wjq
