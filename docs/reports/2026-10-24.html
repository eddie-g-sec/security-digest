Scoped Vulnerability Tracking

Cloud Security

The most urgent item today is CVE-2026-56163, a CVSS 10.0 missing authentication vulnerability in Microsoft Azure Kubernetes Service that allows unauthenticated network-based privilege escalation. This flaw demands immediate patching or mitigation. Other critical vulnerabilities include several CVSS 9.9 issues in Kubernetes, Docker, and Terraform, as well as multiple high-severity flaws across cloud platforms.

Formal Vulnerabilities

AWSCVE-2026-115812CVSS 9.8 · CRITICAL

Summary: A relative path traversal flaw in the model archive extraction of AWS Multi Model Server (versions 1.1.11 and earlier) could allow a remote attacker to execute arbitrary code by providing a crafted model archive. No authentication is required, and the service is network-reachable. The product is end-of-life, so there is no patch; the recommended action is to discontinue use and migrate to a supported solution.

Affected Features / Interoperability: The vulnerability affects the model archive extraction component of Multi Model Server. Downstream functionality that relies on model loading, such as inference pipelines and integration with AWS AI/ML services, could be impacted if the server is compromised. Since the product is end-of-life, any existing deployments may also lack security updates for other components.

Source: https://aws.amazon.com/security/security-bulletins/2026-148-aws/

Actions:

  • Fix: No fixed version available; product is end of life. Migrate to a supported model serving solution.
  • Workaround: Discontinue use of Multi Model Server immediately; isolate any remaining instances from the network.
  • Tradeoff: Discontinuing the service will interrupt any ongoing model serving workflows and require migration to an alternative platform, potentially causing downtime and requiring reconfiguration of pipelines.
AWSCVE-2026-115813CVSS 5.8 · MEDIUM

Summary: An SSRF vulnerability in the model download path of AWS Multi Model Server (versions 1.1.11 and earlier) could allow a remote attacker to cause the server to send requests to internal network destinations by providing a crafted model URL. The attacker could potentially access internal services. No authentication is required if the model download endpoint is exposed.

Affected Features / Interoperability: The vulnerability is in the model download functionality. It could allow an attacker to probe internal network services, potentially leading to further compromise of internal resources. Since the product is end of life, no patches are expected.

Source: https://aws.amazon.com/security/security-bulletins/2026-148-aws/

Actions:

  • Fix: No fixed version; discontinue use and migrate.
  • Workaround: Restrict network access to the Multi Model Server instance, blocking outbound connections to internal networks.
  • Tradeoff: Restricting outbound network access may break legitimate model downloads that rely on internal repositories.
