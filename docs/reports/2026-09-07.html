Database

The most urgent issue is the CISA KEV‑confirmed SQL injection in Sangoma Switchvox (CVE-2026-9586), which allows unauthenticated remote attackers to execute arbitrary SQL on the underlying PostgreSQL database and potentially achieve remote code execution; patching per vendor guidance is required by the September 5, 2026 due date.

Cloud Security

The most urgent threat is the active exploitation of CVE-2026-42880 in Argo CD, a CISA KEV-confirmed critical vulnerability that enables unauthorized extraction of plaintext Kubernetes Secrets, posing a severe risk to healthcare database environments reliant on GitOps workflows.

Formal Vulnerabilities

[Kubernetes] — [CVE-2026-42880] (CVSS 9.6 CRITICAL) 🔴 ACTIVELY EXPLOITED (CISA KEV)

Summary: Argo CD’s ServerSideDiff endpoint contains a missing authorization and data‑masking gap that lets an attacker with read‑only access pull plaintext Kubernetes Secrets from etcd via the Kubernetes API server’s Server‑Side Apply dry‑run mechanism.

Affected Features / Interoperability: The Argo CD GitOps continuous delivery platform; impacts secret management, replication, and client driver integration across Kubernetes clusters.

Source: https://github.com/argoproj/argo-cd/security/advisories/GHSA-3v3m-wc6v-x4x3, https://access.redhat.com/errata/RHBA-2026:12433, https://access.redhat.com/errata/RHSA-2026:20943, https://access.redhat.com/errata/RHSA-2026:20947, https://access.redhat.com/security/cve/CVE-2026-42880

Actions:

  • Fix: Upgrade Argo CD to version 3.2.11 or 3.3.9 (or later).
  • Workaround: Disable ServerSideDiff for production workloads or restrict access to the endpoint via network policies.
  • Tradeoff: Upgrading may cause configuration drift; plan a staged rollout to avoid service interruption.

[Docker] — [CVE-2026-80238] (CVSS 9.3 CRITICAL) 🔴 ACTIVELY EXPLOITED (CISA KEV)

Summary: Dell SCG 5.0 Appliance versions prior to 5.36.00.16 expose an execution‑with‑unnecessary‑privileges flaw, allowing an unauthenticated local attacker to gain root via the exposed Docker socket.

Affected Features / Interoperability: Docker daemon management plane and host‑level control surface; impacts container orchestration and host integrity.

Source: https://www.dell.com/support/kbdoc/en-in/000503426/dsa-2026-382-security-update-for-dell-secure-connect-gateway-virtual-edition-multiple-vulnerabilities?msockid=3021cac2195069ed3194ddad186a68f9

Actions:

  • Fix: Upgrade to Docker Engine 5.36.00.16 or later.
  • Workaround: Remove the Docker socket from world‑writable directories or enforce strict SELinux/AppArmor profiles.
  • Tradeoff: Temporary loss of seamless container creation; requires careful migration planning.
