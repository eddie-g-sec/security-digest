Scoped Vulnerability Tracking

Cloud Security

The most urgent issue is a critical authentication bypass in the UDS Identity Config Keycloak client authenticator (CVE-2026-46389), which allows unauthenticated attackers to authenticate as any client with any secret value, potentially compromising identity management across Kubernetes deployments. This is followed by several other critical vulnerabilities in cloud-native infrastructure components, including Kubernetes operators, Docker-based applications, and cloud platform services, many of which allow unauthenticated remote code execution or privilege escalation.

Formal Vulnerabilities

KubernetesCVE-2026-46389CVSS 10.0 · CRITICALActively exploited · CISA KEV

Summary: A logic error in the `client-kubernetes-secret` Keycloak client authenticator in UDS Identity Config (versions 0.11.0 through 0.26.0) causes the submitted `client_secret` to be overwritten with the mounted Kubernetes secret before comparison. An attacker who can reach the Keycloak token endpoint and knows a `client_id` using this authenticator can authenticate as that client with any `client_secret` value.

Affected Features / Interoperability: Impacts Keycloak identity management within UDS Core deployments, affecting authentication flows for all services relying on this identity provider. Downstream impacts include unauthorized access to Kubernetes resources managed by UDS Core.

Source: https://github.com/defenseunicorns/uds-identity-config/releases/tag/v0.26.1

https://github.com/defenseunicorns/uds-identity-config/security/advisories/GHSA-8mg2-6588-r4hw

Actions:

  • Fix: Upgrade to UDS Identity Config version 0.26.1 or later
  • Workaround: Restrict network access to the Keycloak token endpoint to trusted sources only
  • Tradeoff: Network restrictions may impact legitimate administrative access to Keycloak
KubernetesCVE-2026-83938CVSS 10.0 · CRITICAL

Summary: Missing authentication for critical function in Azure Kubernetes Configuration Service allows an unauthorized attacker to elevate privileges over a network.

Affected Features / Interoperability: Impacts Azure Kubernetes Configuration Service, potentially allowing unauthorized access to Kubernetes cluster configuration and management functions.

Source: https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-83938

Actions:

  • Fix: Apply Microsoft's security update for Azure Kubernetes Configuration Service
  • Workaround: Restrict network access to the service endpoint
  • Tradeoff: Network restrictions may impact legitimate administrative access

Affected Features / Interoperability: Impacts Terraform automation workflows in Kubernetes, allowing forged webhook events to manipulate infrastructure-as-code deployments. Could lead to unauthorized infrastructure changes or destruction.
