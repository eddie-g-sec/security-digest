Scoped Vulnerability Tracking

User Safety: safe

Cloud Security

The most urgent issue is CVE-2025-55190 in Kubernetes (Argo CD), a CISA KEV-confirmed critical vulnerability (CVSS 9.9) allowing unauthorized access to sensitive repository credentials via project-level API tokens, actively exploited in the wild with a due date for remediation. Additional critical vulnerabilities in Docker-based systems (Vasion Print) and high-severity flaws in Kubernetes components (Typebot SSRF, Observability Operator privilege escalation) require immediate attention to prevent credential theft, lateral movement, and infrastructure compromise.

Formal Vulnerabilities

Microsoft AzureCVE-2026-69855CVSS 7.7 · HIGH

Summary: Server-side request forgery (SSRF) in Microsoft Copilot for Azure enables authorized attackers to disclose information over the network. Exploitation requires network access and authorization within the Azure environment.

Affected Features / Interoperability: Azure Copilot's SSRF protection mechanisms. Downstream integrations relying on Copilot's data access may be compromised.

Source: Microsoft Security Update Guide

Actions:

  • Fix: Apply the latest Azure Copilot security update from Microsoft.
  • Workaround: Restrict network access to Copilot endpoints and enforce strict authorization policies.
  • Tradeoff: No significant tradeoff.
KubernetesCVE-2025-55190CVSS 9.9 · CRITICALActively exploited · CISA KEV

Summary: Argo CD versions 2.13.0–2.13.8, 2.14.0–2.14.15, 3.0.0–3.0.12, and 3.1.0-rc1–3.1.1 allow project-level API tokens to retrieve sensitive repository credentials. Exploitation requires network access and a valid project-level token.

Affected Features / Interoperability: Argo CD's project-level permissions and API endpoints. Compromised tokens enable unauthorized access to Git repositories and secrets.

Source: Argo CD Security Advisory

Actions:

  • Fix: Upgrade to Argo CD versions 2.13.9, 2.14.16, 3.0.14, or 3.1.2.
  • Workaround: Rotate all project-level tokens and restrict token permissions.
  • Tradeoff: Temporary service disruption during token rotation.
KubernetesCVE-2025-64709CVSS 9.6 · CRITICAL

Summary: Typebot versions prior to 3.13.1 allow authenticated users to exploit SSRF via webhooks, enabling access to AWS IMDS and extraction of EKS node role credentials. Exploitation requires network access and valid credentials.

Affected Features / Interoperability: Typebot's webhook HTTP Request component and AWS IAM integration. Cluster-wide compromise possible via stolen credentials.

Source: Typebot Security Advisory

Actions:

  • Fix: Upgrade to Typebot version 3.13.1 or later.
  • Workaround: Disable webhook blocks and restrict IMDS access via network policies.
  • Tradeoff: Loss of webhook functionality until patched.
KubernetesCVE-2025-2843CVSS 8.8 · HIGH

Source: Red Hat Security Advisory

Actions:

  • Fix: Apply Red Hat's patch via RHSA-2025:21146.

  • Tradeoff: Reduced monitoring flexibility for tenant users.
