Scoped Vulnerability Tracking

Cloud Security

The single most urgent item is CVE-2025-65200 in LocalStack (Docker), a CRITICAL 9.6 CVSS vulnerability enabling arbitrary code execution via a web-accessible URL; while not yet CISA KEV-confirmed, its severity and exploitability make it the top priority. Other critical vulnerabilities in Docker (Part-DB, Dockhand, FearlessCMS) and Kubernetes (AWS Private CA Connector, identrail, Ansible Operator) also demand immediate remediation.

Formal Vulnerabilities

KubernetesCVE-2026-119115CVSS 8.5 · HIGH

Summary: Incorrect authorization in the issuer resolution logic of AWS Private CA Connector for Kubernetes (aws-privateca-issuer) before v1.10.1 allows an authenticated remote user to obtain certificates, including subordinate CA certificates, signed by a cluster-scoped AWS Private CA issuer that their approval policy does not authorize.

Affected Features / Interoperability: The aws-privateca-issuer component, used for issuing TLS certificates in Kubernetes clusters; downstream certificate issuance and ingress annotation handling could be impacted.

Source: https://aws.amazon.com/security/security-bulletins/2026-156-aws/, https://github.com/cert-manager/aws-privateca-issuer/releases/tag/v1.10.1, https://github.com/cert-manager/aws-privateca-issuer/security/advisories/GHSA-hjrh-q6pg-mh82

Actions:

  • Fix: Upgrade aws-privateca-issuer to v1.10.1 or the AWS Private CA Connector for Kubernetes EKS add-on to v1.10.1-eksbuild.1.
  • Workaround: Restrict cluster-scoped CA issuer approval policies to only authorized users.
  • Tradeoff: May break existing certificate issuance workflows until upgrade is applied.
KubernetesCVE-2026-59185CVSS 8.5 · HIGH

Summary: identrail, a machine identity security platform for AWS, GitHub/OIDC, and Kubernetes, accepts an `installation_id` from the request body or `X-GitHub-Installation-ID` header without verifying the installation belongs to the caller's workspace, allowing a caller to complete GitHub connection with a foreign installation.

Affected Features / Interoperability: The default-on `POST /v1/workspaces/:workspace_id/projects/:project_id/github/connect/complete` endpoint; downstream GitHub integration and OIDC trust relationships could be compromised.

Source: https://github.com/identrail/identrail/commit/835e40517509d6ef5405c27fbf14f579bedff0e7, https://github.com/identrail/identrail/releases/tag/v1.0.2, https://github.com/identrail/identrail/security/advisories/GHSA-cp3j-m783-3ph5

Actions:

  • Fix: Upgrade identrail to version 1.0.2.
  • Workaround: Disable the default-on GitHub connect endpoint or restrict workspace access.
  • Tradeoff: May break GitHub integration until upgrade is applied.
KubernetesCVE-2026-92982CVSS 8.5 · HIGH

Summary: A low-privileged Kubernetes user can exploit a Jinja2 template injection vulnerability in Ansible Operator Plugins by crafting malicious custom resource (CR) specification values, leading to arbitrary code execution and privilege escalation with cluster-wide permissions.

Affected Features / Interoperability: Ansible Operator plugins processing CRs; downstream operator pod execution and service account permissions could be compromised.

Source: https://access.redhat.com/errata/RHSA-2026:68695, https://access.redhat.com/errata/RHSA-2026:87120, https://access.redhat.com/errata/RHSA-2026:87124

Actions:

  • Fix: Upgrade Ansible Operator plugins to a patched version.
  • Workaround: Restrict CR permissions to low-privileged users and sanitize inputs.
  • Tradeoff: May break custom resource processing until upgrade is applied.
DockerCVE-2025-65200CVSS 9.6 · CRITICAL

Summary: In LocalStack 4.9.2, an attacker can execute arbitrary code via crafted content hosted on a web-accessible URL and when passed as `templateURL` to the `_localstack/cloudformation/deploy` endpoint, the hosted content executes inside the Docker container.

Affected Features / Interoperability: LocalStack cloudformation deploy endpoint; downstream CloudFormation deployments and any services relying on LocalStack could be compromised.

Source: http://localstack.com, https://cyberroute.github.io/post/2025-12-11-localstack-hack/, https://github.com/localstack/localstack/blob/aba1ee84592d76f0a88dd286fcd83b65080e31ac/localstack-core/localstack/services/cloudformation/deploy_ui.py

Actions:

  • Fix: Upgrade LocalStack to a patched version (specific version not indicated in advisory).
  • Workaround: Restrict network access to LocalStack and block public exposure of the deploy endpoint.
  • Tradeoff: May break legitimate deployments until upgrade is applied.
DockerCVE-2026-54630CVSS 9.6 · CRITICAL

Summary: Part-DB prior to version 2.12.1 stores uploaded files under the web-served media directory using the client-supplied file extension, and its extension blocklist does not include `phar`, allowing a `.phar` file to keep its extension and be executed as PHP.

Affected Features / Interoperability: Part-DB attachment upload handler; downstream media serving and any PHP-based processing of attachments could be compromised.

Source: https://github.com/Part-DB/Part-DB-server/releases/tag/v2.12.1, https://github.com/Part-DB/Part-DB-server/security/advisories/GHSA-w5m7-3xf7-6g7g, https://github.com/Part-DB/Part-DB-server/security/advisories/GHSA-w5m7-3xf7-6g7g

Actions:

  • Fix: Upgrade Part-DB to version 2.12.1.
  • Workaround: Block `.phar` file extensions in upload handlers.
  • Tradeoff: May break legitimate attachments that use `.phar` extensions.
DockerCVE-2026-57169CVSS 9.6 · CRITICAL

Summary: Dockhand prior to 1.0.34 does not enforce authentication on the WebSocket upgrade request for `/api/containers/<id>/exec`, allowing an unauthenticated attacker with network reach to open a raw WebSocket terminal session and execute commands inside a target container.

Affected Features / Interoperability: Dockhand container exec endpoint; downstream container management and any services relying on Dockhand for remote shell access could be compromised.
