MySQLCVE-2025-50455CVSS 9.1 · CRITICAL

Summary: SQL injection via the order_by parameter of the /customers/search endpoint in EasyAppointments ≤ 1.5.1. Unauthenticated attackers can supply a malicious order_by value, causing time‑based queries, schema enumeration, and potentially remote code execution by writing a PHP shell with INTO OUTFILE when MySQL permits file writing.

Affected Features / Interoperability: The web application’s search endpoint and its dynamic ORDER BY clause; exploitation can break application integrity, lead to data leakage, and compromise the underlying server.

Source: https://github.com/threatlance-org/security-advisories/blob/main/CVE-2025-50455/advisory.md, https://github.com/threatlance-org/security-advisories/blob/main/CVE-2025-50455/poc.py, https://www.linkedin.com/posts/michael-chesang_cve-securityadvisory-appsec-activity-7360754900827365376-Z-IY, https://github.com/threatlance-org/security-advisories/blob/main/CVE-2025-50455/advisory.md

Actions:

  • Fix: Upgrade EasyAppointments to a version that sanitizes the order_by parameter (no specific version listed; consider the latest release if available).
  • Workaround: Implement strict input validation on the order_by field, restrict allowed column names, and disable file‑write capabilities in MySQL (e.g., set `secure_file_priv` to a safe directory) to prevent PHP shell creation.
  • Tradeoff: The workaround may limit legitimate ordering options and could affect existing functionality that relies on dynamic ORDER BY.

  • Tradeoff: Disabling CONNECT may remove support for certain storage features; rebuilding requires custom compilation and testing.
