# Security Digest — 2026-10-27

## Cloud Security

The most urgent issue is **CVE-2026-42869 in Docker**, a critical (CVSS 10.0) vulnerability in SOCFortress CoPilot allowing unauthenticated attackers to forge admin-scoped JWTs and gain full control of security tools due to a hardcoded JWT signing secret. This flaw is actively exploited in the wild, as highlighted in recent news, and requires immediate patching or isolation of affected deployments. Other critical vulnerabilities include Kubernetes' Burrito operator's webhook forgery (CVE-2026-102649, CVSS 9.9) and Docker's unauthenticated RCE in OpenC3 COSMOS (CVE-2026-42088, CVSS 9.6), alongside multiple high-severity issues in Traefik, Argo CD, and Google Cloud Platform services.

### Formal Vulnerabilities

#### AWS — CVE-2026-115418 (CVSS 7.3 HIGH)
**Summary:** SQL injection in AWS CDK's Redshift module allows third parties to execute SQL with superuser privileges via crafted usernames, comments, or passwords. Exploitable by attackers who can influence construct property values.
**Affected Features / Interoperability:** The `@aws-cdk/aws-redshift-alpha` module's database-query custom resource handlers. Could enable unauthorized access to Redshift clusters and privilege escalation.
**Source:** [AWS Security Bulletin](https://aws.amazon.com/security/security-bulletins/2026-151-aws/), [GitHub Release](https://github.com/aws/aws-cdk/releases#release-v2.274.0)
**Actions:**
- Fix: Upgrade to CDK v2.274.0-alpha.0 or later.
- Workaround: Review and revoke existing table grants to PUBLIC.
- Tradeoff: No significant tradeoff.
