# Security Digest — 2026-10-27

## Cloud Security

The most urgent issue is CVE-2026-83938 in Azure Kubernetes Configuration Service, a critical unauthenticated privilege escalation vulnerability (CVSS 10.0) confirmed by CISA KEV, allowing attackers to gain unauthorized network-based access to Kubernetes clusters. Other critical vulnerabilities include Docker CoPilot’s hardcoded JWT secret (CVE-2026-42869) enabling full system compromise, Kubernetes’ Argo CD data-masking gap (CVE-2026-42880) exposing secrets, and Terraform/Burrito’s unsigned webhook acceptance (CVE-2026-102649) permitting unauthorized infrastructure manipulation. Immediate patching or mitigation is required for these and additional high-severity issues across AWS CDK, Azure Himmelblau, and Google Cloud Run MCP.

### Formal Vulnerabilities

#### Kubernetes — CVE-2026-83938 (CVSS 10.0 CRITICAL) 🔴 ACTIVELY EXPLOITED (CISA KEV)
**Summary:** An unauthenticated attacker can exploit a missing authentication flaw in Azure Kubernetes Configuration Service to elevate privileges over the network, gaining unauthorized access to Kubernetes clusters.  
**Affected Features / Interoperability:** Azure Kubernetes Configuration Service’s authentication and authorization mechanisms.  
**Source:** [Microsoft Security Response Center](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-83938)  
**Actions:**  
- Fix: Apply the latest Azure Kubernetes Configuration Service updates.  
- Workaround: Restrict network access to the service endpoint.  
- Tradeoff: Reduced accessibility for legitimate users.  

#### Kubernetes — CVE-2026-46389 (CVSS 10.0 CRITICAL)
**Summary:** A logic error in UDS Identity Config’s Keycloak client authenticator allows attackers to authenticate as any client with any secret value, bypassing client authentication.  
**Affected Features / Interoperability:** UDS Core’s Identity deployment and Keycloak integration.  
**Source:** [GitHub Advisory](https://github.com/defenseunicorns/uds-identity-config/security/advisories/GHSA-8mg2-6588-r4hw)  
**Actions:**  
- Fix: Upgrade to v0.26.1 or later.  
- Workaround: None identified.  
- Tradeoff: None.  

#### Kubernetes — CVE-2026-102649 (CVSS 9.9 CRITICAL)
**Summary:** Burrito’s webhook endpoint accepts unsigned GitHub/GitLab events when `webhookSecret` is omitted or empty, enabling attackers to forge events and manipulate Terraform infrastructure.  
**Affected Features / Interoperability:** TerraformRepository credentials and webhook validation in Burrito.  
**Source:** [GitHub Advisory](https://github.com/padok-team/burrito/security/advisories/GHSA-7m68-72r6-3jx8)  
**Actions:**  
- Fix: Upgrade to v0.13.0 or later.  
- Workaround: Enforce `webhookSecret` for all repositories.  
- Tradeoff: Requires credential reconfiguration.  

#### Kubernetes — CVE-2026-42880 (CVSS 9.6 CRITICAL)
**Summary:** Argo CD’s ServerSideDiff endpoint leaks Kubernetes Secrets to users with read-only access via a data-masking gap.  
**Affected Features / Interoperability:** Argo CD’s Server-Side Apply dry-run mechanism and Kubernetes Secret management.  
**Source:** [GitHub Advisory](https://github.com/argoproj/argo-cd/security/advisories/GHSA-3v3m-wc6v-x4x3)  
**Actions:**  
- Fix: Upgrade to v3.2.11 or v3.3.9.  
- Workaround: Restrict read-only access to sensitive namespaces.  
- Tradeoff: Reduced visibility for legitimate users.
